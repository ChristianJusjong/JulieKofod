# Julie Kofod Hjemmeside

Dette er en portfolio hjemmeside designet til Julie Kofod.

## Sådan ser du siden
Du kan åbne filen `index.html` direkte i din browser (Chrome, Safari, Edge, etc.).

## Indhold
- **index.html**: Hovedsiden med struktur.
- **index.css**: Det visuelle design (Dark mode, animationer, styling).
- **script.js**: Funktionalitet for galleri, filtre og interaktivitet.
- **Billeder/**: Mappen med dine kunstværker (automatisk indlæst).

## Designvalg
- **Stil**: Moderne, premium mørkt tema der får kunsten til at træde frem.
- **Font**: 'Outfit' og 'Playfair Display' for et elegant mix af moderne og klassisk.
- **Features**: 
  - Custom cursor for unik oplevelse.
  - Sortering af værker (Malerier/Skitser).
  - Lightbox (klik på et billede for stor visning).

## Tilpasning
Hvis du vil ændre navnene på billederne eller kategorierne, kan du redigere listen `artworks` i filen `script.js`.
